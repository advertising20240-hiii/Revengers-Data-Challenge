# UX и дизайн интерфейса Revengers CQA

Интерфейс — «пульт контроля качества»: спокойный, точный, с сильной типографической иерархией. Светлая тема по умолчанию (безопасна для проектора), базовый шрифт 16 px, контраст текста ≥ 4.5:1, все элементы доступны с клавиатуры (кнопки — `<button>`, фокус-кольца, Esc закрывает модальные окна, `aria-*` на динамических блоках).

## Структура

| Маршрут | Экран | Назначение |
|---|---|---|
| `#/` | Диалоги | таблица, фильтры, загрузка набора / файла, пакетная оценка с прогрессом (отмена, продолжение), экспорт CSV |
| `#/c/<id>` · `#/c/<id>/l/<line>` | Карточка | транскрипт слева, результат справа; глубокая ссылка на реплику (прокрутка + подсветка; для звонков — перемотка записи) |
| `#/checklist` | Чек-лист | версии, редактор критериев, шаблоны, «Заменить критерий», diff, восстановление, активация, симуляция, «Сохранить и применить» |
| `#/appeals` · `#/appeals/<id>` | Апелляции | очередь (открытые → по уверенности), решение с предпросмотром пересчёта, метрики споров |
| `#/calibration` | Калибровка | точность и κ с 95 % ДИ, матрицы ошибок, holdout, test–retest, расхождения |
| `#/insights` | Инсайты | распределения, доля «Нет», языки/каналы, эскалация, первая реакция, звонки, «Агенты Дума», коучинг |

Роль («Оператор / Проверяющий») переключается в шапке и хранится в `localStorage`: оператор подаёт апелляции в карточке, проверяющий принимает решения. Это разделение действий, не аутентификация.

## Токены (`public/styles.css`, все селекторы под `.cqa-root`)

| Токен | Значение | Смысл |
|---|---|---|
| `--cqa-bg` / `--cqa-surface` | `#f3f5f8` / `#ffffff` | фон страницы / карточек |
| `--cqa-ink` / `--cqa-muted` | `#15191f` / `#5f6977` | основной и вторичный текст |
| `--cqa-accent` | `#1f4f8f` | действия, ссылки, активный раздел |
| `--cqa-yes` / `--cqa-no` / `--cqa-na` | `#1a7f4b` / `#b42c2c` / `#5f6977` | семантика ответов Да / Нет / N/A (плюс мягкие фоны `*-soft`) |
| `--cqa-scale` | `#8a5a00` | ответы по шкале («15 из 20») |
| `--cqa-flag` | `#8e1b2f` | грубая ошибка — отдельный цвет, чтобы флаг никогда не читался как часть балла |
| `--cqa-warn` | `#9a5b00` | «Требует проверки», «под апелляцией», черновики |
| `--cqa-operator` / `--cqa-client` / `--cqa-bot` | `#176b43` / `#2b5c9e` / `#7a8290` | реплики: оператор выделен фоном и рамкой, клиент рамкой, бот/система приглушены |
| `--cqa-hold` / `--cqa-consult` | `#f3ead7` / `#e9e4f4` | сегменты удержания и консультации в звонках (подписаны, не оцениваются как общение с клиентом) |
| `--cqa-evidence` | `#fff3b0` | реплики-доказательства; активная подсветка — `#ffe680` |
| `--cqa-doom` | `#1e3b2e` | единственный «тематический» акцент — заголовок блока «Агенты Дума» |

Шрифты — системный стек (Segoe UI / SF / Roboto), моноширинный для ID, номеров реплик и временных меток; табличные цифры (`font-variant-numeric: tabular-nums`) для выравнивания баллов.

## Решения

- **Большой итог** (3.4 rem) и секции сразу под ним; «не рассчитывается» выводится словами, а не нулём.
- **Флаг отдельно от балла**: баннер грубой ошибки стоит над секциями и подписан «не влияет на итоговый балл» — диалог может быть 100.00 и помечен одновременно.
- **Карточка критерия** всегда в одном порядке: ответ → баллы / вес → эффективный вес → «Почему» → доказательства → проверенный участок (для «Нет») → условие N/A → правило → уверенность. Для проверенных критериев добавляется цепочка «ИИ → проверяющий → итог».
- **Доказательство = ссылка**: клик прокручивает транскрипт, подсвечивает реплику, обновляет адрес (`#/c/<id>/l/<n>`, без перезагрузки экрана) и перематывает запись звонка.
- **Предпросмотр пересчёта** в решении по апелляции и доля весов в редакторе считаются тем же модулем `packages/scoring/index.js`, что и сервер — цифры в интерфейсе никогда не расходятся с сохранёнными.
- **Симуляция** явно помечена «ничего не сохранено»; «Сохранить и применить» показывает, какие критерии ушли в модель, а какие взяты из кэша.
- **Состояния**: скелетоны при загрузке, пустые состояния с следующим действием, ошибки с текстом «что сделать». Недоступность модели — неблокирующий баннер; сохранённые результаты остаются доступны, кнопки оценки отключены с подсказкой.
- **Графики** — собственные inline-SVG (столбцы, гистограмма, точка с усами ДИ, матрица ошибок), подписанные оси, крупные значения, одна палитра.
- **Строки** интерфейса — в `public/i18n/ru.json`; модули — ES с относительными импортами без динамической загрузки, чтобы собрать один HTML-файл для Dynamics 365.
