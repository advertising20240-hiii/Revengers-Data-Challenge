## 11:00 · Получен контрольный `group_id`

```bash
# 1. Сервер запущен
npm start                       # http://localhost:8080

# 2. Загрузить набор (UI: Диалоги → «Загрузить набор» → group_id) или:
curl -s -X POST http://localhost:8080/api/datasets/fetch \
  -H 'Content-Type: application/json' -d '{"group_id":"<CONTROL>"}'
#   → {"group_id":"...","total":N,"source":"api","fetched_at":"..."}
#   Если API организаторов недоступен: получить файл и UI → «Загрузить файл», или
curl -s -X POST http://localhost:8080/api/transcripts/upload \
  -H 'Content-Type: application/json' --data-binary @control.json

# 3. Оценить всё (UI: фильтр group_id → «Оценить все») или:
curl -s -X POST http://localhost:8080/api/evaluate \
  -H 'Content-Type: application/json' -d '{"group_id":"<CONTROL>","all":true}'
#   → {"job_id":"..."}
curl -s http://localhost:8080/api/jobs/<job_id>      # прогресс; UI показывает частичные результаты сразу
```

Таймер: при N ≈ 65 и `CQA_CONCURRENCY=2` ожидать по измеренной задержке из `docs/COST.md`. Если к 11:30 не укладываемся — поднять `CQA_CONCURRENCY` (если провайдер позволяет) или оценивать сначала диалоги, которые покажем.

## Если

| Ситуация | Действие |
|---|---|
| API организаторов не отвечает | файл от организаторов → «Загрузить файл»; формат тот же |
| alem.plus недоступен | автоматический переход на Ollama (`ollama serve`, `qwen2.5:7b`); медленнее, но без сети |
| Оба недоступны | `CQA_PROVIDER=offline`: показываем кэш DEV; замену критерия показываем правилом `first_reaction` (без модели) |
| Сервер не стартует | второй ноутбук; `node server/index.js` напрямую, проверить `PORT` |
| Push не проходит | коммит и тег локально, повторить с токеном; ссылка уже отправлена — жюри проверяет зафиксированный коммит |
