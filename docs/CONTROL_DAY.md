## Бюджет вызовов модели

Измерено на DEV (`reports/runs/alem_qwen3-8_v2.json`): 65 диалогов → 65 вызовов судьи + 2 повторных запроса после валидатора + 15 казахских вторых мнений = **82 вызова**, 370 с при `CQA_CONCURRENCY=3` (17 с задержка одного диалога). Квота alem.plus по заголовкам — 200 запросов на окно неизвестной длины. Для **10 чатов** нужно **10 вызовов судьи + до 10 повторов + KZ-мнения по числу казахских чатов** — ориентир 10–25 вызовов. Правила:

1. **Проверить остаток до набора**: `GET /api/health → provider.quota` (поле появляется после первого живого вызова; если его нет — сделать один вызов «Оценить выбранные» на одном DEV-диалоге с принудительной переоценкой). Записать остаток **R**. Если R < 25 — сразу план Б (п. 5).
2. `.env`: **`CQA_VERIFY=off`** (проверяющая модель в измеренных прогонах была выключена, её вклад не измерен), `CQA_CONCURRENCY=2`. KZ-второе мнение оставить, если R ≥ 40; иначе убрать `ALEM_MODEL_KZ` и перезапустить сервер.
3. **Один вызов судьи на диалог**: «Оценить все» запускать один раз; не нажимать «Второе мнение ИИ» и «Симуляцию» с LLM-критерием до того, как `results/prod/results.json` запушен.
4. **Резерв ≥ 15 вызовов** на живую замену критерия на выступлении; если после прогона R < 15 — показывать замену правилом «Скорость первой реакции» (0 вызовов).
5. **План Б при отказе/квоте**: 429 → автоматически резервная модель (`ALEM_MODEL_FALLBACK`) → если и она недоступна: `CQA_PROVIDER=heuristic` (детерминированные правила по всем критериям, 0 вызовов, в карточке источник подписан «детерминированное правило»; качество ниже — на DEV MAE итога 11.36 против 6.26, но итог будет у каждого диалога; в `results.json` поле `model.mode` отразит режим). Диалоги, которые оценить не удалось, экспорт пишет как `status: "error"` — **никогда не нулями**. **Ollama на ноутбуке не установлена** — как резерв не рассматривать.

## Если

| Ситуация | Действие |
|---|---|
| API организаторов не отвечает | файл от организаторов → «Загрузить файл»; формат тот же; `conversation_id` сохраняются |
| Набор не из 10 чатов | уточнить у организаторов до оценки; `--expect 10` в экспорте специально упадёт при другом числе |
| alem.plus 429 / квота | автоматически резервная модель; затем `CQA_PROVIDER=heuristic` (правила, источник подписан в карточке); жюри сказать прямо: «контрольный набор оценён правилами из-за лимита бесплатного API, DEV — моделью» |
| Диалог не оценился | одна повторная попытка; иначе `status: "error"` с причиной в файле — не скрывать, не ставить нули |
| Провайдер недоступен и правила не подходят | `CQA_PROVIDER=offline`: показываем DEV; замену критерия показываем правилом `first_reaction` |
| Сервер не стартует | второй ноутбук; `node server/index.js` напрямую, проверить `PORT` |
| Push не проходит | токен / второй ноутбук / загрузка файла через веб GitHub; жюри проверяет зафиксированный коммит в публичном репозитории |
