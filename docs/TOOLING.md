# Инструменты и зависимости

## Runtime-зависимости из npm

**Нет.** `package.json` не объявляет `dependencies` и `devDependencies`; `npm install` отрабатывает мгновенно и ничего не скачивает. Это осознанное решение: прототип должен запускаться на чистой машине с Node.js 22 без сети и без рисков цепочки поставки.

## Что используется из Node.js

| Модуль | Для чего |
|---|---|
| `node:http` | REST API и статика (`server/`) |
| `node:fs`, `node:path` | хранилище JSON с атомарной записью, кэш, конфигурация |
| `node:crypto` | хэши промпта/политики/критерия для кэша и трассировки |
| `node:test`, `node:assert` | тесты (`npm test`) |
| `node:child_process` | bash в тестах аудита |
| `node:vm` | выполнение собранного веб-ресурса в тесте сборки |
| `fetch` (встроенный) | API организаторов, OpenAI-совместимые провайдеры, прокси аудио |
| `BigInt` | точная рациональная арифметика движка расчёта |

В браузере: vanilla JS (ES-модули), `fetch`, `<audio>`, inline SVG для графиков, `localStorage` для роли и языка интерфейса. Внешних скриптов и CDN нет.

## Внешние сервисы (опционально, настраиваются через `.env`)

| Сервис | Роль | По умолчанию |
|---|---|---|
| alem.plus — OpenAI-совместимый API моделей | судья, верификатор, казахское второе мнение, запасная модель | включён, если заданы `ALEM_*` |
| Ollama (`http://localhost:11434`) | локальный резерв: `qwen2.5:7b` | включён, если запущен |
| Anthropic API (`claude-sonnet-5-5`, `claude-haiku-5-5`) | платный облачный вариант (не использовался) | **заблокирован** `CQA_ALLOW_CLOUD=0` |
| Langfuse | трассировка вызовов модели | выключен, пока не заданы ключи |
| API организаторов (Power Automate) | источник наборов по `group_id` | `CQA_DATA_URL` |

## Инструменты разработки

- `npm test` — `node --test "tests/**/*.test.js"`.
- `npm run audit` — `scripts/audit-repo.sh` (bash; Git Bash на Windows, bash на Ubuntu).
- `npm run build:d365` — `scripts/build-d365.mjs`, сборка одного HTML-файла без bundler'ов.
- GitHub Actions (`.github/workflows/ci.yml`) — Node 22: тесты, аудит, сборка D365.
- Mermaid в Markdown — диаграммы в `docs/` (рендерятся GitHub).

## Почему не взяли привычные библиотеки

| Кандидат | Почему нет |
|---|---|
| Express / Hono | маршрутов немного, `node:http` достаточно; минус зависимость |
| SQLite (`better-sqlite3`) | нативная сборка — риск на чистой машине; JSON-файлы с атомарной записью покрывают объём хакатона |
| Chart.js | графиков 6–8 типов, inline SVG даёт полный контроль над палитрой под проектор и нулевой вес для D365-сборки |
| dotenv | парсер `.env` — 15 строк в `server/lib/env.js` |
| Ajv | схемы используются в тестах; маленький валидатор в `tests/build.test.js` покрывает нужное подмножество JSON Schema |
| esbuild / rollup | сборка веб-ресурса — переписывание статических импортов, 300 строк в `scripts/build-d365.mjs` |
